
# DevOps End-to-End Project

## Overview
This project documents my hands-on practice with Linux, shell scripting, Git, and GitHub workflows as part of an end-to-end DevOps project.

## Phase 1: Linux + GitHub

### Linux Practice
- Basic Linux commands and file operations
- File permissions and ownership
- Process management and background jobs
- Bash scripting and variables
- Disk usage health-check script
- Loops, file checks, and exit-code handling

### Shell Scripts
- `hello.sh` - Displays server information
- `health-check.sh` - Checks root filesystem disk usage
- `loop-practice.sh` - Demonstrates Bash loops
- `file-check.sh` - Checks whether practice files exist
- `error-check.sh` - Demonstrates file validation and exit codes

## Environment
- OS: Ubuntu Linux
- Terminal: MobaXterm on Windows
- Version Control: Git
- Repository Hosting: GitHub

## Learning Goal
Build practical Linux and Git skills and apply a professional Git branching, review, and release workflow.

## Git Workflow

- Main branch: stable project version
- Feature branches: isolated development work
- Pull requests: review changes before merging
- Tags and releases: identify stable project versions
